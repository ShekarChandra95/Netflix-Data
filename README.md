# Netflix-Data
# 📊 Netflix Movies & TV Shows — Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs an in-depth **Explatory Data Analysis (EDA)** on the Netflix Movies & TV Shows dataset to uncover trends, patterns, and insights about content available on Netflix.

The analysis focuses on understanding content distribution, growth trends, genres, and country-wise production.

---

## 🎯 Objectives

* Analyze the distribution of Movies vs TV Shows
* Identify top content-producing countries
* Explore trends in content release over time
* Discover the most popular genres
* Extract meaningful insights using data visualization

---

## 📂 Dataset

* Source: Kaggle
* Dataset: Netflix Movies and TV Shows
* Features include:

  * Title
  * Type (Movie/TV Show)
  * Director
  * Country
  * Release Year
  * Genre
  * Date Added

## 📈 Key Insights

* 📌 Majority of content on Netflix consists of **Movies**
* 🌍 The **United States** produces the highest amount of content
* 📅 Significant growth in content after **2015**
* 🎭 Drama and International content are among the most common genres
* 📊 TV Shows have increased steadily in recent years

